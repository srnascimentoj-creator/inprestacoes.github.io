# Site IN Prestações de Serviços

Site estático pronto para publicação no GitHub Pages.

## Publicação
1. Crie uma conta no GitHub.
2. Crie um repositório chamado `inprestacoes.github.io`.
3. Envie o arquivo `index.html`.
4. Em Settings > Pages, selecione a publicação pelo branch `main`.
5. O site ficará disponível em `https://inprestacoes.github.io`.

O número de WhatsApp já está configurado no site. Substitua textos/fotos conforme necessário.
